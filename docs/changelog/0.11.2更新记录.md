# 0.11.2

- 放置与粘贴允许相同建筑 DefName 的占地重合，整体替换旧建筑，采用新内容的材质、方向、休眠状态及框架修饰器。
- 多格建筑按完整对象移除并清理全部索引格；整组先验证后修改，其他冲突或组内重叠不会造成部分覆盖。
- 画布预览的可放置判断同步更新；覆盖支持一次撤销、重做。重复刷完全相同的建筑不制造重复对象或空撤销记录。
- 粘贴预览支持 Q 逆时针、E 顺时针旋转 90°，包含整组相对位置和可旋转对象的朝向。预览时 E 优先旋转，退出粘贴后继续用于擦除；R 保留原行为。
- 文本输入优先级保持不变。帮助、右侧操作说明和状态栏同步提示 Q/E。

编译零警告、零错误；259 项检查通过，包括笔刷与粘贴覆盖、多格足迹清理、材质和状态、混合冲突的原子处理、撤销重做、Q/E 正反旋转、输入框及擦除快捷键回归。

本批新增功能，按版本规则从 0.10.2 更新至 0.11.2。
