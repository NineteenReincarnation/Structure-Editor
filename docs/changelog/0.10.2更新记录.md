# 0.10.2

- 右侧新增“导出”页，集中设置目标格式、MP 扩展、XML 目录和自动导出开关，并提供立即导出、另存为 XML、独立内容包和 PNG 预览按钮。
- 保存 JSON 后默认自动导出当前格式 XML；配置按工程持久化，并随撤销快照保留。
- 新工程默认同目录导出；导入 XML 默认使用来源目录；显式指定目录后可分别管理工程及游戏 XML。
- XML 校验或写入失败会显示提示，保留 JSON 编辑和上次成功的 XML。XML 通过临时文件完成后替换；共享文件保留其他 Def。
- 版本从 0.9.2 更新为 0.10.2（本批新增功能，Y 加一）。

编译无警告和错误；240 项检查通过，包括三个导出格式、实际保存入口、开关/路径持久化、导入目录、另存为、共享 XML、失败时保留工程，以及宽窄窗口的导出页面渲染。
