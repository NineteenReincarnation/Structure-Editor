# 0.9.2 修复记录

## 墙体渲染

- `Graphic_Appearances` 按原版材质外观选择目录中的 `Smooth`、`Planks`、`Bricks` 图集，缺少指定外观时回退 Smooth。避免将目录内第一个菜单图标当成连接图集。
- 沿用原版 `MaterialAtlasPool` 的 4×4 图集排列、边缘留白和四向连接掩码。
- 补齐本机游戏解码库的 BC1、BC3、BC4、BC5 支持，保留 BC7；解析游戏 DDS 的通道映射，使 BC4 灰度墙体正常显示。
- 按 `Graphic_LinkedCornerFiller` 的相邻及对角条件填充实心墙块角部。
- 游戏同步目录缺少外观、连接类型字段时，保留对应 XML 元数据。
- 素材图标、画布和导出预览共用材质外观选择，解析结果缓存；绘制不等待贴图解码锁。

## 文本复制粘贴

输入框的快捷键在送往 WinForms 菜单前交给原生文本控件处理，避免 Ctrl+C/V/X/Z 被布局对象编辑命令再次拦截。适用于标识、名称、搜索和只读路径；画布焦点下保留对象复制粘贴。支持 Ctrl+Insert、Shift+Insert 和 Shift+Delete。

## 验证

编译无警告和错误。225 项内置验证通过，含三种材质的 16 种墙体连接、实心块/缺失对角、BC4 通道映射、真实 WinForms 输入框的文本剪切复制粘贴和撤销，以及画布对象复制粘贴回归。已人工查看导出的钢墙、木墙和实心墙块预览。

验证图和运行结果保存在本机 `%LOCALAPPDATA%/StructureEditor/Validation`，不随源码提交游戏素材。
