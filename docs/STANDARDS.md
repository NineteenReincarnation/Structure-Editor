# Structure Editor 设计规范

本文档集中记录 Structure Editor 使用的项目级设计规范。仅收录已确认的规则；未确定的内容不作为正式标准。

## 机械集群

### 集群等级（CP）

机械集群等级按照参与计分的集群设施 **CP 总和**划分：

| 等级 | 总 CP 范围 |
| --- | ---: |
| Ⅰ型 | 0–899 |
| Ⅱ型 | 900–1,799 |
| Ⅲ型 | 1,800–2,999 |
| Ⅳ型 | 3,000–6,998 |
| Ⅴ型 | 6,999–9,999 |
| Ⅵ型 | ≥10,000 |

**计算约定：**

- 只统计机械集群中参与计分的建筑设施。
- 相同设施重复放置时，按各自 CP 乘以数量后累加。
- 墙体、路障不参与 CP 统计。
- 等级由结构当前的设施总 CP 决定；等级区间连续且互不重叠。
- 这是项目内的结构设计分级规范，不代表《RimWorld》原版自带的机械集群等级。

### 规范维护

后续确定的机械集群设计约束、结构编辑与导出标准等，按主题补充到本文件。未经确认的建议数值不写作既定规则。
