# 0.11.3

修复复制超过 128 项后只剩粘贴边框、看不到内容的问题。原代码使用 `items.Count <= 128` 作为整组内容的绘制条件，现已移除这个数量限制。

- 粘贴预览显示实际内容、数量和 Q/E 提示，不透明度提高至 90%；红色冲突边框下也保留内容。
- 使用复制组自身的占地索引处理墙体连接和角部填充，按地形、建筑、单位顺序绘制。
- 对常见大组选区缓存透明预览图，移动时复用；旋转、缩放、可见图层变化和异步贴图刷新后重新生成。
- 单张缓存限制为 4096 边长且不超过 32 MiB。过大或稀疏的布局改为只绘制视野内对象，不隐藏预览、不分配无限尺寸图像。
- 取消粘贴、替换画布/工具及关闭窗口时释放缓存，不改变实际粘贴、覆盖和撤销流程。

编译零警告、零错误；268 项检查通过，包括 2000 项实际内容像素、旋转和缩放后的内容、缓存复用、异步贴图刷新、超大预览回退、取消不修改文档，以及超过 128 项的混合房间布局。已人工检查房间预览与旋转后的 PNG。

本机观测 2000 面墙概览首次构建约 199 ms，缓存后移动约 4.08 ms/帧；这是一次运行的观测，不是跨机器性能保证。图片和详细记录存于本机 `%LOCALAPPDATA%/StructureEditor/Validation`，不提交游戏素材。

本批为错误修复，版本从 0.11.2 更新为 0.11.3。
