# 键盘导航与复古音效

## 导航

结构工坊的导航区域按 **文档标签 → 左侧页签 → 素材筛选 → 素材/结构/CP 列表 → 编辑图层工具栏 → 画布** 排列。结构库、CP 页没有素材筛选区，导航会自动跳过。

| 操作 | 快捷键 |
| --- | --- |
| 在工作区域间切换 | `F6` / `Shift+F6` |
| 聚焦当前左侧页签的搜索框 | `Ctrl+F` |
| 聚焦编辑图层工具栏 | `Ctrl+L` |
| 直接切换到素材、结构、CP 列表 | `Alt+1/2/3` |
| 从画布跳到素材列表 | `A` |
| 从画布跳到编辑图层工具栏 | `W` |
| 在文档标签、左侧页签中立即切换激活项 | `A/D`、`←/→` |
| 从已激活的文档／左侧标签进入下一工作区域 | `Enter` |
| 在列表中选上一项/下一项 | `W/S`、`↑/↓` |
| 从素材列表进入上方筛选区 | 在第一项再按 `W` / `↑`，焦点落在最近的「来源」 |
| 从筛选区返回素材列表 | 「来源」未展开时按 `S` / `↓` |
| 在素材/结构/CP 列表间切换 | 列表中 `A/D` |
| 展开/收起结构库中的文件夹 | 选中文件夹时 `Tab`（`Enter` 也可） |
| 在筛选框之间移动 | 下拉框收起时 `W/S` |
| 展开/收起当前筛选下拉框 | `Tab`（`Enter` 可确认） |
| 在展开的筛选下拉框中上下选择 | `W/S`、`↑/↓` |
| 选中当前 XML 中所有同 DefName 对象 | 画布上 `Alt+左键` |
| 保留画布原有的图层切换 | 画布获得焦点后 `Tab` / `Shift+Tab` |
| 保留打开文档切换 | `Ctrl+Tab` / `Ctrl+Shift+Tab` |

**页签导航立即生效，不存在只移动预览光标的第二选中状态。** 搜索输入框保留正常输入，WASD 不会被导航接管；材料、旋转等对象检查器的下拉列表保留原有操作。鼠标点击不需要先启用键盘模式。

`Alt+左键` 依据 `Kind + DefName` 匹配当前文档中的实际放置对象，不按朝向、材料或是否休眠区分；跨地图文件和其他打开的文档不会互相选中。此操作只改变选择集合，不改变 XML 内容。

## 声音设计

界面反馈采用实体游戏手柄的干脆按键声：中频塑料触点轻响为主、短促橡胶回弹为辅。相比最初的尖锐电子提示音，高频经过限制；相比上一版沉闷的低频敲击，提高 1–3 kHz 的清晰度并缩短尾音。各操作保留轻重差别，不采用明显的旋律式变音；高速 W/S 导航限制重叠密度，减少听觉疲劳。

- `MP_UiSound` 是唯一的提示音 API；各 UI 直接发出 `Cue`，不持有音频设备。
- `NAudio 2.2.1` 负责 Windows waveOut 音频设备适配及浮点声音混合；合成波形属于本项目原创素材，未复制 lilt 的音频或外部版权资源。
- `lilt` 仍仅用作物理动画／动效参考（参见 [lilt 说明](third-party/lilt.md)），声音由本项目自主设计。
- 输出设备缺失或初始化失败时自动静音，不能影响编辑器功能。
- 设置里现有的「界面音效」开关保持有效。
